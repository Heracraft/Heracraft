- **[repose](https://repose.herakraft.co)**, cloud machines where coding agents keep working after you close your laptop. I own and operate it.
- **[coolify-tools](https://github.com/Heracraft/coolify-tools)**, a Go CLI that streams encrypted backups over SSH and hardens self-hosted Coolify servers.
